The Clay email waterfall we use (~92% find rate)

closed:in is a Clay Solutions Partner. We run a 4-provider waterfall inside Clay that hits ~92% find rate on B2B emails at the lowest possible credit cost. Here is the exact provider order, the credit logic per step, and the fallback paths.

Provider order

Run these in series, not parallel. Each step only runs if the previous step failed. This saves credits dramatically.

Step 1: Findymail

Best hit rate on small business + personal email finders. Cheapest credits in our stack. Start here for most lists.

If Findymail email is not null → set primary_email = Findymail email, skip rest

Step 2: Datagma

Strong in EU markets where Findymail lags. Run only when Findymail returns null. Pays for itself on NL/BE/DE lists.

If primary_email is null AND country is EU → run Datagma

Step 3: Apollo

Volume player. Best for US lists. Lower per-credit cost but variable accuracy. Catches what others miss in tech B2B.

If primary_email is still null → run Apollo

Step 4: Hunter (verification only)

If we got an email from any of the above, run Hunter verification on the result. Catches false positives before sending. Final quality gate.

If primary_email is not null → verify with Hunter, drop if verification = invalid

Credit math

On a typical 1,000-prospect list with our waterfall, we use roughly:

  • ~600 Findymail credits (~60% hit rate stops here)
  • ~150 Datagma credits (subset of remaining 40%)
  • ~200 Apollo credits (subset still missing)
  • ~750 Hunter verification credits (verify everything that came back)

Total cost: roughly EUR 12-18 per 1,000 prospects with ~92% find rate. Much cheaper than running all 4 providers in parallel.
