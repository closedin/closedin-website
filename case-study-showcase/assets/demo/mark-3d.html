closed:in glass mark

Scroll to turn it, move the mouse to tilt it. This page is the reference embed for /assets/js/mark-3d.js.

Embed recipe: a square box with data-mark-3d and a poster image inside, the import map above, gsap + ScrollTrigger loaded, then:

import('/assets/js/mark-3d.js').then(m => m.init(box, { gsap, ScrollTrigger, lenis: null, isMobile: false, trigger: '[data-trigger]' }));

CONFIG and MARK at the top of mark-3d.js hold every tunable: rest pose, material (color, transmission, tint), scroll turns, tilt strength, idle spin. The geometry mirrors /assets/brand/closedin-mark.svg.
